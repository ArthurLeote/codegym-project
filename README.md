# Exercícios de Java — CodeGym

Repositório para registrar minha prática de Java com exercícios do CodeGym.

## Objetivos

- Praticar lógica de programação e sintaxe Java.
- Registrar minha evolução.
- Estudar Git e GitHub na prática.
- Criar consistência na resolução de problemas.

## Organização

Os exercícios seguem a estrutura criada pelo projeto/plugin do CodeGym.
Cada commit representa uma tarefa concluída, validada ou revisada.
